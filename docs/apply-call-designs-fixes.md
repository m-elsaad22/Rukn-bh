# إصلاحات شكل الصفحات من Call-main على موقع البحرين الحي

المصدر البصري: `Call-main.zip` (19 ملف HTML من تصميم ركن التطور). النسخة الإماراتية في الملفات استُبدلت بهوية البحرين.

الموقع: https://www.rukn-eltatawer.com/bh  
القالب مقفول (`DISALLOW_FILE_EDIT`). مسار التنفيذ الحي: إضافة **Code Snippets** المعرّف **5**.

## ما الذي أُصلح

1. **هيدر مكسور / شريط أبيض:** CSS التصميم (`header` ثابت بعرض كامل بلا `::before`) يُحقَن في `wp_footer` بأولوية 9999 حتى يتغلّب على `main.css`.
2. **بقايا الإمارات:** إخفاء `.uae-svg`، استبدال «اختر الإمارة» و«دبي، الإمارات» و`/bh/en/`، وإعادة توجيه المسودات `grass-wall-*` و`artificial-grass-grdn-*`.
3. **أرشيف المدن HTTP 500:** اعتراض `cities` وعرض صفحة مدينة بشكل التصميم بدل قالب المدينة المعطوب.
4. **Soft 404:** روابط غير موجودة تعرض صفحة 404 بشكل Call-main بدل إعادة توجيه صامتة للرئيسية.
5. **صفحات رقيقة:** من نحن، تواصل (نموذج → واتساب)، المدن (12 بطاقة)، خدماتنا (9 تصنيفات)، الخصوصية (إشارة PDPL البحريني)، شروط، أسئلة شائعة، ومقابلات إنجليزية.
6. **أزرار عائمة:** اتصال + واتساب ظاهران. الرقم `+971586634710` مؤقت حتى يتوفر +973.
7. **ملفات ZIP** في مكتبة الوسائط تُحذف لأنها ليست محتوى زائر.

## التشغيل

```bash
export WP_BASE='https://www.rukn-eltatawer.com/bh'
export WP_USER='melsaad'
export WP_APP_PASSWORD='…'
python3 tools/apply_call_designs.py
```

الكود: `tools/bh-fix-snippet.php` + `tools/pages/*.html`.

لا يُغيَّر `show_on_front=posts` لأن رئيسية KAYAN تعتمد ودجات `@index`.
