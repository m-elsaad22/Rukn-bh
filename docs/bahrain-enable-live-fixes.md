# تفعيل إصلاحات البحرين على الموقع الحي

الإضافة `Rukn BH Live Fixes` 1.1.0 تُثبَّت وتُفعَّل على https://www.rukn-eltatawer.com/bh لأنها لا تحتاج تعديل ملفات القالب (`DISALLOW_FILE_EDIT`) وسكربت WPCode 3257 يبقى مسودة لا يمكن تشغيله من WP-CLI.

## ماذا تفعل بعد التفعيل
- `robots.txt` نصي لمسار `/bh/`
- أرشيفات CPT الفارغة (`/services/` وغيرها) 404 بدل 500
- قائمة الهيدر تُملأ إذا خرجت فارغة
- أزرار الاتصال مخفية وواتساب الإمارات مؤقتاً
- سكيما محلية للمنامة بدل الحقول الفارغة
- استبدال «اختر الإمارة» و«دبي» الظاهرين في HTML

الكود: `tools/rukn-bh-live-fixes/` والملف المضغوط `tools/rukn-bh-live-fixes.zip`.
