## الخلاصة التنفيذية

المحتوى العربي موجود بكمية كبيرة: **1648 مقالاً منشوراً** على شبكة **206 خدمات × 8 مدن**. المقالات طويلة (~2000 كلمة) لكن التفرّد ضعيف، وكل مقال يحمل نفس الصورة ونفس رقم واتساب الإماراتي ونفس مقتطف القالب.

المشكلة ليست «نقص مقالات» بقدر ما هي:

1. **هوية بحرينية ناقصة:** لا رقم +973، و`+971586634710` داخل **كل** المقالات و8 صفحات، وفي Schema.
2. **صفحات تعريفية رقيقة** (من نحن / تواصل / خدمات / مدن / إنجليزي / خصوصية / مدونة).
3. **فجوة تغطية:** الموقع يدّعي 12 مدينة بينما المقالات تغطي 8 فقط (جدحفص، سار، توبلي، الحد بلا مقالات).
4. **أنواع محتوى فارغة:** خدمات، تقييمات، أسئلة شائعة، أسعار، أعمال، قبل/بعد = صفر.
5. **المحتوى مخزَّن بطريقة ستنتقل مع استبدال القالب:** CSS داخل `post_content`، رقم إماراتي في المقتطفات، صورة بارزة موحّدة، خريطة HTML فيها روابط مسودات و404.

بعد نسخ قالب الإمارات ستبقى هذه المشاكل ما لم تُعالَج في ووردبريس نفسه.

## 1) حرج — هوية، ثقة، أو فهرسة مضلّلة

### 1.1 رقم إماراتي داخل كل المحتوى البحريني

- البحث في REST عن `971586634710` يعيد **1648 مقالاً** و**8 صفحات**.
- المقتطف النمطي لكل العيّنات:

  `{العنوان}: معاينة في … ثم عرض مكتوب. واتساب 971586634710 — بدون اتصال هاتفي.`

- صفحات تضع الرقم كنص ورابط: `contact-us`, `about-us`, `our-services`, وكل الصفحات الإنجليزية الخمس.
- JSON-LD على الرئيسية:

  `"telephone": "+971586634710"` و`"addressCountry": "BH"` و`"addressLocality": "المنامة"`

  هاتف دولة أخرى على كيان بحريني = إشارة E-E-A-T سلبية وقد تُرفض في النتائج المحلية.

- **لا يوجد +973** في الصفحات أو المقالات المفحوصة.
- تناقض داخل المحتوى: المقتطف يقول «بدون اتصال هاتفي» بينما صفحات التواصل تستخدم `tel:+971586634710`.

**الإجراء:** عند توفر رقم بحريني: استبدال جماعي في `post_content` + `excerpt` + الصفحات + Schema. حتى ذلك الحين: توحيد الرسالة على واتساب الإماراتي المؤقت **فقط**، وحذف `tel:` من نصوص الصفحات حتى لا يُطلب اتصال برقم غير بحريني.

### 1.2 الصفحة الأمامية ليست صفحة هبوط

إعداد ووردبريس: `show_on_front = posts` و`page_on_front = 0`. الرئيسية = تدفق أحدث المقالات، بلا `canonical` ظاهر، بلا `meta description`، بلا H1 في HTML المفحوص، وhreflang يشير إلى `https://rukn-eltatawer.com/bh/en/` وهي **404**.

لا توجد صفحة رئيسية مكتوبة لنية «شركة خدمات منزلية في البحرين».

### 1.3 روابط مفقودة تُعامل كالرئيسية (Soft 404)

| الرابط | الاستجابة الفعلية |
|---|---|
| `/bh/this-page-does-not-exist-xyz-999` | 302 → الرئيسية بحالة **200** |
| `/bh/terms/` | 200 الرئيسية |
| `/bh/faq/` | 200 الرئيسية |
| `/bh/grass-wall-manama/` (مسودة) | 200 بعنوان الرئيسية، بلا canonical |
| `/bh/wp-sitemap.xml` | 302 → الرئيسية |

جوجل قد يفهرس المسودات والروابط المكسورة كمحتوى مكرر للرئيسية. المسودات الـ16 تحتاج **301** إلى المقال المعتمد (`wall-grass-*` و `artificial-grass-*`) لا الإبقاء كمسودة صامتة.

### 1.4 خريطة HTML تنشر روابط ميتة

`html-sitemap` (1255 رابطاً):

- ما زالت تضم **8** `grass-wall-*` و**8** `artificial-grass-grdn-*` (مسودات).
- رابط `https://rukn-eltatawer.com/bh/services/` → **404**.
- تغطي ~1244 رابطاً فريداً مقابل **1648** مقالاً منشوراً (نقص ~400 مقال).
- لا `index.php` في المحتوى الحالي (تحسّن عن الفحص السابق).

### 1.5 أرشيفات المدن في السايتماب تُرجع 500

Rank Math يفهرس:

`/bh/city/manama/` … `/budaiya/` (8 روابط)

وكلها تفحص كـ **HTTP 500**. كذلك `/city/hidd|saar|jidhafs|tubli/` (مدن بلا مقالات) تُرجع 500. حتى بعد استبدال القالب: هذه الصفحات تحتاج محتوى هبوط لكل مدينة، لا أرشيفاً فارغاً أو معطوباً.

### 1.6 ملفات ZIP في مكتبة الوسائط

مرفوعان علناً تحت `/wp-content/uploads/`:

- `rukn-bh-live-fixes.zip`
- `rukn-bh-seo.zip`

هذا ليس محتوى للزائر، وقد يكشف أدوات داخلية. يُحذفان من المكتبة ويُمنع رفع إضافات عبر الوسائط.

## 3) المقالات — الكمية جيدة والتفرّد ضعيف

### 3.1 الشبكة

- 206 قوالب عنوان × 8 مدن = 1648. كل قالب يظهر 8 مرات بالضبط.
- المدن ذات المقالات: المنامة، المحرق، الرفاع، مدينة حمد، مدينة عيسى، عالي، سترة، البديع (206 لكل منها).
- مدن في التصنيف بلا مقال: **جدحفص، سار، توبلي، الحد**.
- لا عناوين مكررة بعد تحويل 16 مقال تآكل إلى مسودة (تحسّن).
- لا مقال بلا مدينة معروفة في العنوان.

### 3.2 النمطية (من التدقيق السابق + إعادة التأكد على عيّنات 2026-09-22)

ما زال كل مقال عيّنة يبدأ بنفس كتلة CSS داخل المحتوى، ونفس هيكل H2 المتكرر عبر المدن («خدمة ميدانية داخل {مدينة}»، «علامات تساعدك تقرر»، «الخلاصة»، «كيف تُقاس التكلفة»…). فقرات نمطية سابقة وُجدت في 99% من المقالات (نطاق العمل، «لا أسعار ثابتة»، «أرسل على واتساب»). هذا يضعف التفرّد أمام جوجل حتى لو بقيت 2000 كلمة.

عيّنات 22 سبتمبر: 1978–2403 كلمة، H2 محلية جزئياً (الجفير، أم الحصم في مقالات المنامة) — هذا اتجاه جيد يجب توسيعه لا الاكتفاء به.

### 3.3 CSS مخزَّن داخل المقال

`post_content` لكل العيّنات يبدأ بـ:

`.kayan-article .responsive-table{...}` + أنماط جداول ونصائح.

هذا **محتوى قاعدة بيانات** لا ملف قالب. بعد نسخ قالب الإمارات ستظهر هذه الكتلة كنص/تنسيق مكرر 1648 مرة، أو تتعارض مع CSS الجديد.

**الإجراء:** شريط CSS من بداية كل `post_content` قبل أو مع ترحيل القالب.

### 3.4 صورة واحدة لكل الموقع

- `featured_media = 1587` على **كل** المقالات.
- الصورة نفسها تُعاد داخل المتن: `rukn-eltatawer-picture.webp`.
- `alt` في المكتبة فارغ (النص البديل داخل المقال يُولَّد من العنوان — جيد نسبياً، لكن الملف نفسه بلا alt).
- لا صور قبل/بعد، لا صور أحياء، لا رسوم خدمات. 11 ملفاً في المكتبة لا تكفي 1648 صفحة محلية.

## 5) SEO تقني مرتبط بالمحتوى (لا بعيوب واجهة القالب)

### 5.1 العناوين الوصفية

عناوين HTML للصفحات تكرر العلامة:

`من نحن — ركن التطور البحرين - ركن التطور - البحرين`

Rank Math يضيف لاحقة الموقع فوق عنوان الصفحة الذي يحتوي الاسم سلفاً.

المقالات أفضل: `عامل دهانات في المنامة | ركن التطور البحرين`.

الرئيسية: لا description / لا og في الاستخراج.

### 5.2 السايتماب

`/bh/sitemap_index.xml` يعمل (Rank Math). يشمل:

- 4 ملفات مقالات: 502+500+500+148 = **1650** عنصراً منها الرئيسية داخل `post-sitemap1` (تكرار مع `page-sitemap`).
- `page-sitemap`: 13 رابطاً (12 صفحة + الرئيسية مكررة).
- `category-sitemap`: 11 بينها **Uncategorized** وتصنيف إنجليزي فارغ.
- `cities-sitemap`: 8 روابط كلها **500**.
- لا سايتماب لوسوم (جيد إن بقيت الوسوم ضعيفة) ولا لـ CPT الفارغ (جيد).

`robots.txt` لـ `/bh/` صحيح كنص ويعرض السايتماب. `robots.txt` للجذر يذكر سايتماب البحرين **بدون www** بينما بعض صفوف الدول بـ www — توحيد المضيف مطلوب على مستوى الشبكة.

### 5.3 hreflang

الرئيسية تعلن `en` → `/bh/en/` (404). الصفحات العربية/الإنجليزية ليست أزواجاً في Polylang. إما ربط حقيقي أو حذف hreflang الإنجليزي حتى لا يُرسل جوجل إلى 404.

### 5.4 www مقابل غير www

`siteurl` = `https://rukn-eltatawer.com/bh` (بدون www). الطلبات على www تُخدم أيضاً. كل روابط REST بدون www. يُثبت Canonical host واحد (يفضَّل ما يستخدمه Search Console).

### 5.5 `/bh/ar/`

يحوّل إلى مقال عشوائي: `artificial-grass-aali`. يجب أن يحوّل إلى الرئيسية العربية لا إلى مقال حديقة في عالي.

### 5.6 التصنيف الافتراضي

`default_category = 1` (Uncategorized). أي مقال جديد بلا تصنيف يقع في السلة الإنجليزية المفهرسة.

## 6) ما تحسَّن منذ التدقيق السابق (للسياق، ليس الثغرة)
